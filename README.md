# 📊 4. CNN Architecture Benchmarking — Tiny ImageNet

### `Custom CNN • ResNet18 • MobileNetV2 • Transfer Learning`

A comparative deep learning study evaluating multiple CNN architectures on the **Tiny-ImageNet 200-class classification problem**.

The project compares:

```text
                 Tiny-ImageNet
                       │
          ┌────────────┼────────────┐
          │            │            │
          ▼            ▼            ▼
      Custom CNN    ResNet18    MobileNetV2
          │            │            │
          └────────────┼────────────┘
                       ▼
                Model Evaluation
                       │
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
     Accuracy       Precision        Recall
        │              │              │
        └──────────────┼──────────────┘
                       ▼
                    F1 Score
```

### 📈 Evaluation

The project goes beyond accuracy and investigates:

* Precision
* Recall
* F1-score
* Confusion matrices
* Class-wise performance
* Model efficiency
* Generalization
* Accuracy vs computational trade-offs

The repository specifically implements a custom CNN, ResNet18 and MobileNetV2 and includes model comparison and visualization workflows.

### 💡 Key Learning

The project helped me understand an important ML engineering principle:

> **The best model is not always the largest model — architecture selection depends on the problem, accuracy requirements and computational constraints.**

🔗 **Project:**
https://github.com/tensorbytes0202/Comparative-Analysis-of-CNN-Architectures-on-Tiny-ImageNet

# 📈 Engineering Principles

### 01 — Build, Don't Just Learn

I prefer implementing concepts through projects rather than learning them only theoretically.

### 02 — Understand the Fundamentals

Frameworks change.

Fundamentals remain.

That's why I focus on:

```text
Algorithms
Mathematics
Deep Learning
Computer Vision
Data Structures
System Design
```

### 03 — Measure Everything

A model isn't good because it runs.

It should be evaluated.

```text
Accuracy
Precision
Recall
F1
Latency
FPS
Memory
Inference Cost
```

### 04 — Think in Systems

A model is a component.

The application around the model determines whether it becomes useful.

### 05 — Keep Building

Every project is an experiment.

Every experiment creates another question.

And every question becomes another system to build.
